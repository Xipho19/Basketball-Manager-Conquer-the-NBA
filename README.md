# 篮球经理：征服联盟

一款浏览器端篮球经理游戏的 **COMIC RED / WHITE** 美漫红白皮肤版。

- 扩军建队 / 接手球队
- 选秀、交易、自由市场、薪资与轮换
- 完整常规赛、季后赛与休赛期
- L0 新手引导
- 本地 IndexedDB 存档
- Lamps 平台排行榜、云存档、激励视频接入（平台内自动启用）

## 运行

这是一个纯静态站点，推荐通过任意静态服务器访问：

```bash
python -m http.server 8000
```

然后打开 <http://127.0.0.1:8000/>。

也可以在 GitHub 仓库的 **Settings → Pages** 中选择 `Deploy from a branch`，分支选 `main`、目录选 `/ (root)`，启用后通过 GitHub Pages 地址游玩。

> 不建议直接双击 `index.html` 以 `file://` 方式打开；浏览器的 iframe 与 IndexedDB 限制可能导致游戏无法正常启动。
