# 篮球经理：征服联盟

美漫红白风格的篮球经理 H5 游戏，基于 2026-11-23 线上版本的单页静态构建。

- 在线试玩：<https://xipho19.github.io/Basketball-Manager-Conquer-the-NBA/>
- 入口：`index.html`（单页游戏，不再使用 iframe 外壳）
- 底座版本：`source-5c54a129d626ddfa`（2026-11-23）
- 皮肤：`comic-red`（美漫红白）

## 玩法

- 32 队联盟：扩军建队或收购现有球队，处理扩军保护名单与扩军交易桌
- 选秀：新秀生成规则、抽签前新秀预览、两轮选秀、新秀签约
- 交易：拟真 / 经典两种交易模式、交易控制台、主动报价、续约记录
- 自由球员：开季自由球员、薪资空间实时校验、RFA/UFA、竞价与截止日
- 球队战术：9 种进攻、7 种防守、3 档节奏，赛前布置与赛后复盘
- 轮换：10 人轮换、定位互换、非卖品、指定训练
- 发展联盟：下放培养、随日期自动参赛、召回一队
- 其他：联盟杯、1·3·6 阵容适配赛、赛季奖项、休赛期合同选项与成长

## 存档

- 使用浏览器 IndexedDB：`basketball-franchise-manager` / `career-saves`
- 共 10 个存档槽位
- 旧版经典存档可直接读取；首次载入会要求选择「拟真 / 经典」交易模式，选择后继续保留生涯进度

## 本地运行

这是纯静态站点，需要通过 HTTP 访问（不能直接双击 `index.html`）：

```bash
python -m http.server 8712 --bind 127.0.0.1
```

然后打开 <http://127.0.0.1:8712/index.html?night=0>。

## 说明

- 页面不包含入口 iframe、`<object>`、`<embed>`，也不包含站外平台名称或加群引导
- 游戏内的 Lamps 云存档、排行榜、激励视频由平台宿主提供；本地静态打开时相关能力不可用，属正常现象
- 素材仅用于个人学习与演示
